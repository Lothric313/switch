# SWITCH

Русскоязычное портфолио студии: React + Vite, JavaScript, CSS, Tailwind CSS, GSAP. TypeScript не используется. Исходные Staggered Menu, Flex Carousel и Folder взяты из официального реестра React Bits через MCP; изменения касаются палитры, русского языка, доступности и открытия карточек в модальном окне. Horizon Bloom написан отдельно на SVG и CSS.

## Запуск

Нужен Node.js 22.12+ (проверено на Node 24).

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

Откройте http://localhost:5173. Express и Vite работают вместе: отдельный сервер для формы запускать не нужно. После изменения `.env` перезапустите сервер. Без почтовых реквизитов сайт работает, но форма возвращает честную ошибку о недоступности отправки.

Продакшен на Node:

```powershell
npm run build:client
npm start
```

Сервер раздаёт `dist/client` и `/api/contact`. Укажите в окружении `HOST=0.0.0.0`, нужный `PORT` и `APP_ORIGIN=https://ваш-домен`. За единственным доверенным reverse proxy можно установить `TRUST_PROXY=1`; иначе оставьте 0. Настройте HTTPS на хостинге. `npm run preview` показывает только собранный интерфейс, без почтового API.

## Добавление работы и видео

1. Сохраните обложку и видео в `public/works/`, например `project.webp` и `project.mp4`.
2. Добавьте объект в `src/config/works.js`:

```js
{
  id: 'my-project',
  title: 'Название проекта',
  category: 'Лендинг',
  year: '2026',
  cover: '/works/project.webp',
  video: '/works/project.mp4',
  description: 'Короткое описание задачи и результата.',
  demo: false,
}
```

Карусель и счётчик обновятся автоматически. До добавления ролика оставьте `video: ''`: модальное окно покажет обложку. Видео создаётся только при открытии проекта, имеет `preload="none"`, постер и управление; при закрытии останавливается и удаляется. Автовоспроизведение зависит от политики браузера: если звук блокируется, пользователь сможет нажать Play. Для обложек рекомендуются WebP/AVIF шириной 1200–1600 px и размером до 300 КБ. Видео — MP4 H.264 с `faststart`, желательно до 1080p. Возможен и прямой HTTPS URL видео с вашего CDN.

Добавлены три предоставленных видеопримера: AURA, «ЛАПУСИК» и Lothric Jewelry. Ролики оптимизированы до 720p; обложки сохранены в WebP. Оригинальные MP4 остаются в вашей исходной папке.

Язык переключается кнопками RU / EN внутри меню и сохраняется в браузере. Тексты интерфейса находятся в `src/config/copy.js`; переводы работ — в поле `en` файла `works.js`, тарифов — в `services.js`. Карусель двигается перетаскиванием с зажатой левой кнопкой мыши; на телефоне — горизонтальным свайпом. После отпускания ближайшая карточка плавно выравнивается по центру; сжатие карточек и видимый счётчик отключены. Колесо прокручивает страницу, клавиши ← / → остаются доступны для управления с клавиатуры. В просмотре показываются видео и название проекта.

## Тарифы и соцсети

- `src/config/services.js` — название, цена (`price`), подпись цены (`priceLabel`), описание и состав услуги. Меняйте число и подпись вместе. Один и тот же конфиг используют форма и сервер: подменённая клиентом цена в письмо не попадёт. `null` обозначает индивидуальный расчёт.
- `src/config/socials.js` — ссылки Telegram, TikTok и YouTube. Сейчас стоят адреса платформ, замените на профили студии.
- `src/styles.css` и `src/refinements.css` — палитра, размеры, адаптивная сетка. Используется предоставленный Inter 4.1 из `public/fonts/InterVariable.woff2`, сторонних запросов к шрифтам нет.

## Отправка почты

Все значения задавайте только в `.env` или серверных переменных окружения хостинга. Не используйте префикс `VITE_` для секретов. `.env` исключён из Git.

### Resend

Создайте API-ключ в Resend, подтвердите домен отправителя и задайте:

```dotenv
MAIL_PROVIDER=resend
RESEND_API_KEY=ваш_ключ
CONTACT_TO=адрес_студии@example.com
MAIL_FROM=SWITCH <hello@ваш-подтверждённый-домен>
APP_ORIGIN=http://localhost:5173
```

В продакшене замените `APP_ORIGIN` на точный адрес сайта без завершающего слеша. Для нескольких получателей разделяйте адреса запятыми. После заполнения отправьте пробную заявку и проверьте доставку в почтовом ящике.

### SMTP / Nodemailer

Для Node-хостинга доступна альтернатива:

```dotenv
MAIL_PROVIDER=smtp
CONTACT_TO=адрес_студии@example.com
MAIL_FROM=SWITCH <hello@ваш-домен>
SMTP_HOST=smtp.провайдер.ru
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=ваш_логин
SMTP_PASS=пароль_приложения
```

Обычно порт 465 требует `SMTP_SECURE=true`; для 587 используется STARTTLS. Точные параметры возьмите у своего почтового провайдера. В ключах и паролях в репозитории нет необходимости.

Форма проверяет данные на клиенте и сервере, использует honeypot и минимальное время заполнения, ограничивает тело запроса 12 КБ, а частоту — пятью попытками за 15 минут на IP. В Node лимит хранится в памяти процесса; при нескольких экземплярах используйте общий store или лимиты хостинга. Полные тексты заявок и секреты в логи не пишутся.

## GitHub Pages

Для репозитория `Lothric313/switch` подготовлен workflow `.github/workflows/deploy.yml`. В Settings → Pages выберите Source: GitHub Actions. После push в `main` сайт собирается и публикуется по адресу `https://lothric313.github.io/switch/`.

Сборка Pages использует `VITE_BASE_PATH=/switch/` и `VITE_STATIC_HOST=true`: видео, обложки, логотип и шрифты работают из подпапки. GitHub Pages не запускает почтовый сервер, поэтому форма показывает, что приём заявок недоступен. Node и Sites по-прежнему используют серверную отправку.

## Sites / serverless (сборка)

`npm run build` дополнительно создаёт `dist/server/index.js` для приватного предпросмотра в Sites. Он использует Resend; SMTP доступен в Node-версии. В Sites задайте `RESEND_API_KEY`, `CONTACT_TO`, `MAIL_FROM` и при необходимости `APP_ORIGIN` в runtime environment хостинга — локальный `.env` туда не переносится.

В демосборку Sites встроены небольшие статические файлы. Для больших видео используйте Node-хостинг с `npm run build:client` либо CDN и HTTPS-ссылку в конфиге. Защита от частых запросов в Worker действует в пределах одного isolate; для публичного сайта включите edge rate limit.
